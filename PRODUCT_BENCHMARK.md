# Product Benchmark

This benchmark studies current vocabulary, SRS, and Japanese-learning products to identify product patterns worth learning from. It is not a feature checklist. The focus is information architecture, study workflow, review quality, feedback, and perceived polish.

## Selected Competitors

### Anki

- Target user: self-directed learners, power users, students with custom materials.
- Core value: reliable SRS and deck control.
- Home structure: deck list with due/new counts.
- Navigation: deck-centric hierarchy, browser/settings as secondary tools.
- Start studying: select deck, study due/new cards.
- Flashcard interaction: reveal answer, grade recall.
- Review/SRS: due reviews first; filtered decks for cram, failed cards, tags, review ahead.
- Progress: counts, card states, deck-level due/new numbers.
- Daily flow: work through due cards with daily limits.
- Search/dictionary: strong card browser, not a dictionary product.
- Favorites/difficult: tags, filtered decks, lapses/failed-card review.
- Audio: card media can include audio.
- Motivation: mostly utilitarian; productivity over gamification.
- Visual design: functional, dense, low decoration.
- Polished: trust, predictability, persistence, SRS clarity.
- Confusing: advanced concepts and setup burden.
- Learn from: clear due/new deck entry, review-first mental model, custom study as secondary.
- Not for us: expose deck-management complexity on mobile home.

### Quizlet

- Target user: students studying terms quickly.
- Core value: easy flashcard creation/search plus multiple study modes.
- Home: sets/classes/recent content.
- Navigation: content set first, modes within set.
- Start studying: choose a set, then Flashcards/Learn/Test.
- Flashcard interaction: flip/swipe, mark known.
- Review/SRS: Learn adapts question formats and repeats missed terms.
- Progress: set completion, known/unknown, test scores.
- Daily flow: less strict SRS; more session-based.
- Search/dictionary: massive set search.
- Favorites/difficult: starred terms and struggled terms.
- Audio: term audio available for many languages.
- Motivation: short sessions, achievement framing.
- Visual design: clean, student-friendly, strong card surfaces.
- Polished: modes are subordinate to a study set, not equal app-level buttons.
- Confusing: search/community content quality varies.
- Learn from: group practice modes under one vocabulary context.
- Not for us: AI/content-sharing emphasis.

### Duolingo

- Target user: casual daily language learners.
- Core value: habit-forming structured path.
- Home: one dominant learning path, streak/currency/profile in top bar.
- Navigation: few core tabs; product blog notes craft issues around inconsistent headers/spacing.
- Start studying: tap next lesson on path.
- Flashcard interaction: varied exercise types, immediate feedback.
- Review/SRS: review appears as practice/legendary/mistake repair rather than raw queues.
- Progress: path progress, streak, quests, XP.
- Daily flow: clear next action every session.
- Search/dictionary: not central.
- Favorites/difficult: mistakes become practice targets.
- Audio: integrated listening and pronunciation.
- Motivation: streak is prominent; daily goal reinforces habit.
- Visual design: playful but highly systematized.
- Polished: one clear next action and cohesive feedback.
- Confusing: gamification can obscure learning depth.
- Learn from: reduce choice overload; make the primary next step obvious.
- Not for us: heavy game economy, character-driven world.

### Memrise

- Target user: learners wanting useful words, native media, speaking practice.
- Core value: relevant words plus native speaker audio/video.
- Home: journey/lessons and activity tracking.
- Navigation: lessons, videos, words, conversations.
- Start studying: pick current lesson/review.
- Flashcard interaction: word/phrase practice with media.
- Review/SRS: still SRS-oriented, but new experience emphasizes speaking and real use.
- Progress: My Words and My Activities.
- Daily flow: practice features consolidate learned content.
- Search/dictionary: Word Information acts like personal dictionary.
- Favorites/difficult: known/difficult status on words.
- Audio: strong focus on native voices and pronunciation practice.
- Motivation: activity metrics, less abstract points than older design.
- Visual design: modern consumer learning.
- Polished: words connect to real audio/media context.
- Confusing: product transitions removed some old offline/community modes.
- Learn from: learned words should live in a personal dictionary with status.
- Not for us: online AI/video features.

### WaniKani

- Target user: kanji/vocab learners who accept a prescribed SRS path.
- Core value: kanji mnemonics and strict review cadence.
- Home: lessons, reviews, forecast, extra study.
- Navigation: dashboard widgets, item pages, review session.
- Start studying: Start Reviews or Lessons.
- Flashcard interaction: typed answer, correct/incorrect feedback.
- Review/SRS: levels, intervals, wrap-up, recent mistakes.
- Progress: level progress, SRS stage, review forecast.
- Daily flow: do reviews when due, then lessons.
- Search/dictionary: item pages are rich but not general dictionary-first.
- Favorites/difficult: recent mistakes and item info.
- Audio: vocabulary readings/audio.
- Motivation: level unlocking and progress forecast.
- Visual design: bold but organized.
- Polished: review queue is sacred; extra study is secondary.
- Confusing: strict system can feel rigid.
- Learn from: home should separate "Reviews due" from "Extra practice".
- Not for us: locked curriculum or radical/kanji-only worldview.

### Renshuu

- Target user: broad Japanese learners from beginner to advanced.
- Core value: flexible Japanese-specific quizzing and schedules.
- Home: dashboard/schedules/stats/community.
- Navigation: schedules, resources, games, settings.
- Start studying: choose a schedule or daily quiz.
- Flashcard interaction: multiple question types, settings per schedule.
- Review/SRS: Japanese-specific mastery schedules; weaker items move forward.
- Progress: mastery, stats, schedules, daily challenges.
- Search/dictionary: advanced search and community lists.
- Favorites/difficult: weak materials and customizable study.
- Audio: large native audio library, pitch/accent data.
- Motivation: mascot, coins, garden, quests, manga unlocks.
- Visual design: cute and dense.
- Polished: very Japanese-aware, but still flexible.
- Confusing: many settings and features can overwhelm.
- Learn from: Japanese-specific quiz settings and weak-item focus.
- Not for us: large mascot/game ecosystem.

### Bunpro

- Target user: Japanese grammar/JLPT learners.
- Core value: SRS reviews with typed answers and grammar explanations.
- Home: learn/review buttons, progress, forecast.
- Navigation: dashboard, decks, reviews, grammar library, stats.
- Start studying: reviews if due; learn new grammar/vocab.
- Flashcard interaction: cloze/typed answer with hints.
- Review/SRS: clear intervals, ghost reviews after mistakes, review queue.
- Progress: SRS stages, forecast graph, profile stats.
- Daily flow: reviews first, then learn.
- Search/dictionary: content search and grammar library.
- Favorites/difficult: cram/troubled grammar.
- Audio: native audio on examples.
- Motivation: progress through SRS, less childish.
- Visual design: modern web app, data-rich.
- Polished: forecast and review controls make system legible.
- Confusing: queue visibility and review controls require learning.
- Learn from: typed recall, review forecast, mistake repair.
- Not for us: grammar-heavy explanations beyond dataset.

### jpdb

- Target user: immersion/Japanese media learners.
- Core value: dictionary + SRS + deck extraction from content.
- Home: decks/review state/search.
- Navigation: dictionary, decks, SRS, media-derived lists.
- Start studying: due cards or selected media deck.
- Flashcard interaction: vocabulary/kanji cards, contextual sentences.
- Review/SRS: custom memory model, global progress across decks.
- Progress: known vocabulary across all decks.
- Daily flow: review queue, then new items from chosen content.
- Search/dictionary: core product; sentence parsing and deck creation.
- Favorites/difficult: lapses and deck filtering.
- Audio: dictionary/card audio where available.
- Motivation: readiness to consume target media.
- Visual design: utilitarian, information-dense.
- Polished: learning vocabulary is tied to why the learner cares.
- Confusing: dense and technical.
- Learn from: global vocabulary progress should not duplicate across chapters/sessions.
- Not for us: online media/deck extraction.

### Kitsun

- Target user: serious SRS learners and immersion learners.
- Core value: elegant SRS with integrated dictionaries and customizable cards.
- Home: combined dashboard with decks/reviews/stats.
- Navigation: decks, dictionary, reading tools, cards.
- Start studying: select due reviews or deck.
- Flashcard interaction: customizable card layouts and answers.
- Review/SRS: ranks/stages, customizable intervals, leeches.
- Progress: streaks, stats, deck progress.
- Daily flow: due reviews and selected quick study.
- Search/dictionary: strong Japanese dictionary card generation.
- Favorites/difficult: leeches/quickstudy.
- Audio: card audio generation and vocabulary audio.
- Motivation: streaks and stats.
- Visual design: premium/dark-modern.
- Polished: powerful tools feel integrated around one SRS model.
- Confusing: customization can be too much for casual users.
- Learn from: quickstudy should be secondary to due review.
- Not for us: template/HTML card customization.

### Japanese Kanji Study

- Target user: Android Japanese learners focused on kanji, words, writing.
- Core value: offline, optimized Japanese study utility.
- Home: sets/search/study modules.
- Navigation: kanji sets, quizzes, writing, search, info.
- Start studying: select set or shortcut.
- Flashcard interaction: configurable display, swipe/actions.
- Review/SRS: guided SRS add-on; ratings filter learned items.
- Progress: study time, quiz stats, rankings by stats.
- Daily flow: reminders and custom sets.
- Search/dictionary: strong offline kanji/word search.
- Favorites/difficult: favorite examples/kanji; wrong repeats.
- Audio: native audio and TTS support.
- Motivation: less gamey, utility quality.
- Visual design: dense but professional Android utility.
- Polished: offline search, customization, one-hand use.
- Confusing: many modes.
- Learn from: offline polish and search speed matter.
- Not for us: stroke detection or full kanji dictionary scope.

### Satori Reader

- Target user: intermediate Japanese readers.
- Core value: contextual reading with curated explanations and audio.
- Home: personalized dashboard with started/bookmarked/new episodes.
- Navigation: series, reader, study list, heatmap, discussions.
- Start studying: continue reading or review saved cards.
- Flashcard interaction: contextual flashcards with sentence/audio.
- Review/SRS: cards by new/active/learned, stats and next due.
- Progress: heatmap, card stats, reading progress.
- Daily flow: continue story or review cards.
- Search/dictionary: contextual definitions in reading flow.
- Favorites/difficult: bookmarks/favorite series/cards.
- Audio: sentence and episode audio; downloadable offline content.
- Motivation: story continuity and heatmap.
- Visual design: calm, premium, reading-first.
- Polished: context and audio make vocabulary meaningful.
- Confusing: subscription/content scope.
- Learn from: vocabulary cards should preserve context sentence and audio.
- Not for us: long-form reading platform.

### Busuu

- Target user: mainstream learners seeking structured CEFR-style courses.
- Core value: short lessons, smart review, community correction.
- Home: course path/progress/review.
- Navigation: learn, review, community/profile.
- Start studying: current lesson or review tab.
- Flashcard interaction: flashcards/writing for vocabulary review.
- Review/SRS: weak/medium/strong vocabulary mix.
- Progress: course level, certificates, streak.
- Daily flow: lesson and review habit.
- Search/dictionary: vocabulary review list with search.
- Favorites/difficult: word strength states.
- Audio: audio playback and video flashcards.
- Motivation: streaks, certificates, community.
- Visual design: mainstream polished, restrained.
- Polished: review strength labels are easy to understand.
- Confusing: premium gating.
- Learn from: "weak/medium/strong" is friendlier than raw SRS labels.
- Not for us: community correction and CEFR certificates.

### Drops

- Target user: casual vocabulary learners.
- Core value: 5-minute visual vocabulary habit.
- Home: short session entry, categories, streak.
- Navigation: categories, review dojo, profile.
- Start studying: tap 5-minute session.
- Flashcard interaction: game-like matching/selection.
- Review/SRS: Review Dojo after enough words; flags words needing practice.
- Progress: learned word count and streak.
- Daily flow: complete preferred session length.
- Search/dictionary: not central.
- Favorites/difficult: words needing practice.
- Audio: word audio.
- Motivation: short session, streak, playful visuals.
- Visual design: highly visual, polished, minimal text.
- Polished: strong time-boxed promise.
- Confusing: too game-like for serious JLPT learners.
- Learn from: constrain daily session scope.
- Not for us: icon-only vocabulary games.

### Lingvist

- Target user: vocabulary learners who want efficient adaptive study.
- Core value: personalized repetition and risk management.
- Home: hub with weekly history, deck progress, Learn button.
- Navigation: hub, learn, decks/progress.
- Start studying: Learn button in bottom utility belt.
- Flashcard interaction: sentence cloze and recall.
- Review/SRS: new words blocked until at-risk words are reduced.
- Progress: active word progress, weekly history.
- Daily flow: learn 50 cards regularly; review risk first.
- Search/dictionary: less central.
- Favorites/difficult: at-risk words.
- Audio: listening support.
- Motivation: progress and routine, not noisy gamification.
- Visual design: clean, focused.
- Polished: the hub tells users exactly what to do.
- Confusing: algorithm opacity.
- Learn from: prioritize due/at-risk before new words.
- Not for us: opaque global algorithm.

### HeyJapan

- Target user: beginner Japanese/JLPT N5-N3 learners.
- Core value: roadmap from kana to conversation and JLPT.
- Home: beginner path and lessons.
- Navigation: roadmap, vocabulary, conversation, JLPT.
- Start studying: next roadmap lesson.
- Flashcard interaction: visual flashcards and drills.
- Review/SRS: level-based practice.
- Progress: roadmap and JLPT level.
- Daily flow: short daily lessons.
- Search/dictionary: not core.
- Favorites/difficult: practice targets.
- Audio: voice recognition and listening.
- Motivation: beginner-friendly path.
- Visual design: colorful consumer mobile.
- Polished: clear "what next" for beginners.
- Confusing: content quality concerns in reviews.
- Learn from: roadmap framing for JLPT.
- Not for us: broad all-skills scope.

### Mochi

- Target user: JLPT learners who want one structured app.
- Core value: JLPT N5-N1 curriculum with SRS, grammar, vocab, reading, listening, speaking.
- Home: structured lessons and progress.
- Navigation: lessons, SRS, skills.
- Start studying: next JLPT curriculum item.
- Flashcard interaction: SRS cards for kana/kanji/vocab.
- Review/SRS: Anki-like spaced repetition.
- Progress: JLPT curriculum progression.
- Daily flow: structured next lesson and reviews.
- Search/dictionary: reading tap-to-lookup.
- Favorites/difficult: implied SRS weak cards.
- Audio: native audio, listening, speaking comparison.
- Motivation: "know what to learn next".
- Visual design: modern all-in-one.
- Polished: positioning solves app-switching anxiety.
- Confusing: broad scope risks bloat.
- Learn from: JLPT roadmap and single next step.
- Not for us: grammar/listening/speaking curriculum beyond imported vocab.

## Cross-Product Patterns

1. The home screen rarely exposes every feature at the same level. It usually presents one primary next action.
2. Mature SRS products distinguish Reviews Due, New/Lessons, and Extra Practice.
3. Practice modes are contextual. They are usually launched from a set, deck, schedule, review queue, or roadmap.
4. Progress is motivational when it is connected to action: at-risk words, due reviews, daily goal, streak, level progress.
5. Production polish comes from consistency more than decoration: repeated headers, predictable buttons, stable feedback, and few color meanings.
6. Japanese-specific products provide audio, kana/kanji readings, examples, and typed recall, not just generic flashcards.
7. Extra modes should not compete with the primary daily flow.

## Product Implications For 蜡笔GO

- Home should become a "today hub": what to study now, why, and how much remains.
- "Start" should not dump the user into level selection as the only primary path. Daily Review should be primary when words exist.
- Browse, import, clear, favorites, difficult words, and practice modes should be secondary or grouped.
- Study modes should share the same vocabulary progress model and completion state.
- Visual personality can stay warm and playful, but the color system must become intentional.
- Automatic pronunciation is a core study affordance, not a decorative feature.
